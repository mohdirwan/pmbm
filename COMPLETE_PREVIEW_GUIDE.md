## Preview Features:

### Data Siswa Card (Blue Header)
- Jalur Pendaftaran
- NISN, NIK
- Nama Lengkap
- Jenis Kelamin, Agama
- Tempat/Tanggal Lahir
- Alamat lengkap (Kecamatan, Kab/Kota, Provinsi)
- No. HP, Email

### Asal Sekolah Card (Cyan Header)
- Nama Sekolah
- Alamat Sekolah

### Data Orang Tua Card (Green Header)
- **Data Ayah:** Nama, NIK, Pekerjaan, Penghasilan
- **Data Ibu:** Nama, NIK, Pekerjaan, Penghasilan
- **Data Wali:** Nama, Pekerjaan (jika ada)

### Rekap Nilai Card (Yellow Header)
- Table dengan semua semester
- Jumlah Nilai
- Rata-Rata Nilai (highlighted)

### Dokumen Upload Card (Gray Header)
- Grid layout 2 kolom
- Each file shows:
  - ✅ **Icon** based on type (PDF=red, Image=green, Other=blue)
  - ✅ **Label** dokumen
  - ✅ **Filename**
  - ✅ **File size** in KB
  - ✅ **File extension** badge
  - ✅ **Check icon** (success indicator)

## Troubleshooting:

**Q: Modal shows but data empty?**
A: Check form field names match formData.get() calls

**Q: File preview shows "Tidak ada dokumen"?**
A: Make sure files are actually uploaded before opening preview

**Q: Some data shows "-"?**
A: That field is empty or not filled yet
